# /ig-repurpose — Una idea, muchas piezas

Sigue `instagram/reglas.md`. Lee `instagram/marca.md`.

## Entrada
El contenido original (texto, transcripción o enlace que puedas leer) y si es **propio** o **de terceros**.
- Propio: puedes reutilizar frases e historias.
- De terceros: solo como inspiración; extrae ideas y crea algo original citando la fuente si se usa un dato.

## Pasos
1. Extrae las **ideas atómicas** (5–10): cada una una afirmación, dato, historia o paso que se sostenga solo.
2. Asigna a cada idea el mejor formato:
   - Opinión fuerte / historia → **reel** (`/ig-reel`)
   - Proceso, lista, comparación → **carrusel** (`/ig-carousel`)
   - Pregunta al público / detrás de cámaras → **stories** (`/ig-story`)
   - Frase memorable → **post de una imagen** con texto
   - Reflexión larga → **caption larga** sobre foto
3. Produce en borrador las 3 piezas más fuertes completas; el resto como lista con gancho + formato.
4. Propón el orden de publicación (ver `/ig-plan`) y cómo enlazarlas entre sí (ej.: «en el carrusel del jueves lo explico paso a paso»).

## Si el original es un reel propio que funcionó
Propón también: versión 2 con otro gancho, versión respondiendo al comentario más frecuente, y versión carrusel. Guarda en `instagram/borradores/`.
